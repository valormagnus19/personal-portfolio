# Personal Computer Science Portfolio

A clean, responsive, and modern personal portfolio website built using vanilla **HTML5**, **CSS3**, and **JavaScript**. Designed specifically for Computer Science students and Software Developers to showcase their skills, projects, coursework, and contact details.

---

## Features

- **Responsive Design**: Optimized for all screen sizes, from mobile phones to desktop displays.
- **Dark / Light Mode**: Interactive theme toggle with user preference saved in `localStorage`.
- **Clean Semantic Markup**: Built with standard HTML5 semantic elements for accessibility and SEO.
- **Custom CSS Variables**: Modular and easily tweakable styling system.
- **Interactive Contact Form**: Client-side form handling with simulated status feedback.
- **Developer-Focused Sections**: Highlights technical skills, featured projects with tech tags, and relevant CS coursework/experience.
